# Direction Triage (fast pass)

Use before committing to a full memo. Ten minutes, not two hours.

| Question | Answer |
|---|---|
| What is the direction, in one sentence? | |
| What triggered the look? | |
| Trigger type | |

| What breaks if this does not happen? | |
| Who obviously benefits (and is therefore likely crowded)? | |
| Where might economics actually sit? | |
| Inside, edge, or outside the circle of competence? | |
| What is the single most decisive unknown? | |
| Cheapest next check that would resolve it | |

**Triage outcome:** [Drop / Park / Full memo]

Dropping here is a good outcome, not a failed session. Most directions should not survive triage.
